# R5 导师测试步骤

请将 ZIP 完整解压到较短目录（建议 `D:\Hematuria-R5` 或桌面一级目录）；不要放入多层长目录，Windows 未启用长路径时会静默漏解压运行组件。

1. 完整解压 ZIP，不要在压缩软件内运行。
2. 双击根目录唯一入口 `启动血尿训练系统.cmd`，等待“本地患者服务已就绪”。
3. 随机选择一个病例，询问 5—8 个自然问题。
4. 提交阶段 1，进入“检查与开单”。
5. 勾选至少两个检查，点击“开立并返回结果”，确认报告和“已获资料”增加。
6. 提交阶段 2，确认可进入阶段 3 并选择检查结果作为证据。
7. 关闭窗口后重新启动，确认病例、阶段和结果恢复。
8. 如有问题，运行 `VERIFY-PACKAGE.ps1`，再从应用“辅助设置”导出脱敏诊断。

本包仅用于医学教学模拟，不用于真实诊疗；不需要安装 Node、Python 或联网下载模型。
