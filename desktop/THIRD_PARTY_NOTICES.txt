Hematuria Training System desktop runtime notices
==================================================

This repository pins runtime downloads in runtime-manifest.json. The installer
contains the Node.js runtime and llama.cpp CPU binaries, but never the model.

The lightweight 1.7B and standard 4B files are separate optional downloads.
Neither model file is copied into the installer or portable application.

The build tooling must preserve the license files distributed with downloaded
runtime archives. See runtime-manifest.json for immutable sizes and SHA-256
digests.
